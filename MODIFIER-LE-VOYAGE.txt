MODIFIER L'APP DU VOYAGE — sans rien reconstruire
====================================================

Tout ce qui change pendant le voyage est dans UN fichier : voyage.json
Les voyageurs voient la nouvelle version à la prochaine ouverture de l'app (avec réseau).

LE PLUS SIMPLE : LA PAGE D'ÉDITION
  Ouvrez https://monaccompagnateur.ca/solden-voyage-2027/editeur.html
  (ajoutez-la à vos favoris; elle n'est liée nulle part dans l'app).
  Formulaires par section → « Aperçu » pour voir le résultat → « Publier ».
  Première fois : section « Connexion à GitHub », collez votre jeton (étapes dans la page).

MODIFIER DIRECTEMENT LE FICHIER (méthode avancée)
  1. github.com → votre dépôt → cliquez voyage.json
  2. Icône crayon (Edit this file)
  3. Faites la modification, puis « Commit changes »
  4. Attendez 1 à 2 min, puis vérifiez avec l'adresse de l'app suivie de ?verif
     ex. https://VOTRE-COMPTE.github.io/solden-voyage-2027/?verif
     → bandeau vert = fichier valide · bandeau rouge = erreur de syntaxe (l'app garde l'ancienne version)

COMPTE À REBOURS (dans "depart")
    "depart": { "date": "2027-03-05", "heure": "16:45", "fuseau": "America/Montreal" }
  - Le carré « J – » de l'Accueil compte jusqu'à cette heure (le décollage).
  - Le rendez-vous à la porte reste affiché à part dans « Prochain rendez-vous ».

LIENS DU GROUPE (dans "liens") — WhatsApp, Facebook, etc.
  Collez le lien d'invitation entre les guillemets de "url" :
    { "type": "whatsapp", "titre": "Groupe WhatsApp du voyage", "url": "https://chat.whatsapp.com/XXXXXXXX" },
    { "type": "facebook", "titre": "Groupe Facebook du voyage", "url": "https://www.facebook.com/groups/XXXXXXXX" },
  - Un lien avec "url": "" reste caché. Dès qu'il est rempli, il apparaît sur l'Accueil
    (« Rejoindre le groupe ») et dans l'onglet Infos.
  - Types possibles : whatsapp, facebook, instagram, site, autre
  - On peut en ajouter d'autres (ex. album photo partagé) :
    { "type": "autre", "titre": "Album photo", "detail": "Déposez vos photos ici", "url": "https://..." }
  Où trouver les liens :
    WhatsApp : ouvrir le groupe › nom du groupe › Inviter via un lien › Copier le lien
    Facebook : ouvrir le groupe › Partager › Copier le lien

AJOUTER UNE ANNONCE (dans "annonces")
    {
      "date": "2027-03-08T07:30",
      "fuseau": "Europe/Vienna",
      "texte": "Rendez-vous déplacé à 9 h 15 au pied du Gaislachkogl."
    },
  - "date" : l'annonce n'apparaît qu'à partir de cette heure → on peut les préparer d'avance.
  - "fuseau" : "America/Montreal" pour l'heure de Montréal (tout ce qui se passe avant le vol au départ de YUL),
    "Europe/Vienna" pour l'heure d'Autriche (à partir de l'arrivée à Zurich).

AJOUTER UN RENDEZ-VOUS AU PROGRAMME (dans "items" du bon jour)
    { "heure": "09:00", "titre": "Départ ski en groupe", "lieu": "Gare aval Gaislachkogl", "note": "Forfait en main.", "rdv": true }
  - "rdv": true → étiquette « Rendez-vous » et compte à rebours sur l'accueil
  - "aConfirmer": true → étiquette « À confirmer » (retirez-la quand c'est confirmé)
  - "heure": "" → élément sans heure

RÉUNION TEAMS ET AUTRES RENCONTRES AVANT LE DÉPART (dans "avantDepart")
    { "date": "2027-02-19", "fuseau": "America/Toronto", "heure": "19:00", "titre": "Réunion d’information sur Teams",
      "lieu": "En ligne · Microsoft Teams", "note": "…", "lien": "https://teams.microsoft.com/…", "lienTexte": "Rejoindre la réunion Teams", "rdv": true }
  - Avec une "heure", la réunion devient le « Prochain rendez-vous » sur l'Accueil et entre dans le calendrier.
  - "lien" vide = pas de bouton. L'app est publique : activez la salle d'attente Teams, ou laissez le lien vide
    et envoyez-le dans le groupe WhatsApp.
  - Retirez "aConfirmer": true quand la date est confirmée.

BAGAGES (dans "bagages") — sert à l'app ET à l'affiche affiche-bagages.html
  "soute" et "cabine" : une ligne par sac { "t": "Sac à skis", "d": "Skis et bâtons" }
  "noteSoute", "important" (encadré rouge), "conseils" (petites lignes en bas de l'affiche)
  La carte « Vos bagages pour l'avion » apparaît sur l'Accueil les 3 semaines avant le départ.

DOCUMENTS (dans "documents")
  "liste" : cases à cocher pour chaque voyageur · "notes" : petites phrases sous la liste

AJOUTER UN LIEU SUR LA CARTE (dans "lieux")
    { "id": "rdv1", "nom": "Point de rencontre", "detail": "Devant la billetterie", "lat": 46.9600, "lng": 11.0060 }
  Coordonnées : appui long sur le lieu dans Google Maps ou Plans → copier les deux nombres.

BONNES ADRESSES (dans "adresses") — onglet Ski : restos sur les pistes, après-ski et bars
    { "nom": "Zum Kuckuck", "categories": ["apres-ski"], "domaine": "soelden", "secteur": "Village · gare aval Giggijoch",
      "description": "…", "acces": "…", "infos": "Ouvert dès 15 h", "tags": ["Musique live", "Terrasse"],
      "lien": "", "lienTexte": "", "coupDeCoeur": true, "lat": null, "lng": null }
  - "categories" : "restaurant", "apres-ski" ou "pratique" (une adresse peut en avoir plusieurs)
  - "domaine" : "soelden" ou "gurgl" → l'adresse suit le domaine choisi par le voyageur
  - "coupDeCoeur": true → l'adresse passe en premier avec « ★ Coup de cœur de l'accompagnateur »
  - "lat"/"lng" remplis → l'adresse apparaît aussi sur la carte (bouton « Voir sur la carte »)
  - Le plus simple : section « Bonnes adresses » de la page d'édition.

POINTS MÉTÉO (dans "meteo" › "points")
    { "domaine": "soelden", "nom": "Mi-station", "lat": 46.950, "lng": 10.986, "altitude": 2174 },
  - "domaine" : "soelden" ou "gurgl" → le point s'affiche selon le domaine choisi (Sölden, Gurgl, Les deux).
  - "altitude" en mètres règle la prévision; les coordonnées peuvent être approximatives.
  - Pour un autre voyage, remplacez par les points de la nouvelle station.

WEBCAMS (dans "webcams") — onglet Météo
    { "domaine": "soelden", "nom": "Giggijoch", "altitude": 2290,
      "image": "https://wtvpict.feratel.com/picture/37/5762.jpeg?dcsdesign=feratel4",
      "lien": "https://webtv.feratel.com/webtv/?cam=5762&design=v4&c2=0&c8=0" }
  - "image" : photo affichée (si elle ne charge pas, la case affiche « Vue en direct ↗ »)
  - "lien" : la vue en direct officielle, ouverte en touchant la case
  - Pour retirer une webcam, supprimez son bloc.

RÈGLES JSON À RESPECTER
  - Texte toujours entre guillemets droits "…"
  - Virgule entre deux éléments, jamais après le dernier d'une liste
  - Pas de guillemet " à l'intérieur d'un texte : utilisez « » ou ’

CONFIDENTIALITÉ
  L'adresse de l'app est publique : aucun nom de voyageur, numéro de chambre,
  de téléphone personnel ou de réservation dans voyage.json.
  Un lien d'invitation WhatsApp/Facebook permet à quiconque l'a de demander à rejoindre :
  activez l'approbation des membres dans les réglages du groupe.

APERÇU D'UNE DATE (pour tester)
  Ajoutez ?apercu=2027-03-07T08:00 à l'adresse pour voir l'app comme ce jour-là (heure d'Autriche).
