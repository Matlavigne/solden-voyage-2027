Créer le jeton (une seule fois)
  1. Sur github.com : photo de profil › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Nom : « Éditeur voyage ». Expiration : jusqu’après le voyage (ex. 30 avril 2027).
  3. Repository access : Only select repositories › choisissez le dépôt de l’app seulement.
  4. Permissions › Repository permissions › Contents : Read and write. Rien d’autre.
  5. Generate token, copiez-le (il commence par github_pat_) et collez-le ci-dessus.

Le jeton ne permet de modifier que ce dépôt. Il reste sur cet appareil et n’est jamais publié. En cas de perte du téléphone, supprimez-le dans la même page GitHub.

Liste du groupe (accompagnateur seulement)

…

Chambres, niveaux, sous-groupes de ski, téléphones. Ces renseignements sont chiffrés avec une clé accompagnateur, distincte de la phrase du voyage, dans un fichier à part (groupe.json). Les voyageurs ne la reçoivent jamais : ils ne peuvent pas lire la liste. Dans l’app, ouvrez Infos › « Accès accompagnateur ».

Une personne par ligne, champs séparés par des tabulations (copier-coller d’Excel) ou des points-virgules, dans cet ordre : Nom ; Chambre ; Niveau ; Sous-groupe ; Téléphone ; Notes.
